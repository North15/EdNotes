Project setup

How this drops into a real app

Package @north15/ednotes-richtext

The live demo above imports source files directly so this page can run with zero build steps. In a real product, use the published npm package or the .NET package assets shown below.

Browser app with npm

Install the package, import the public API, and initialize the editor against the textarea your app already owns. 

npm install @north15/ednotes-richtext

import EdNotesRichText from "@north15/ednotes-richtext";

EdNotesRichText.init({
  selector: "#notes",
  plugins: "core formatting blocks lists links tables tasks math",
  toolbar:
    "undo redo | blocks | bold italic underline | link unlink | numlist bullist task | table math | removeformat",
  theme: "professional",
  promptLink: () => window.prompt("Enter URL", "https://"),
  promptMath: () => window.prompt("Enter LaTeX", "x^2"),
});

ASP.NET with the NuGet package

Serve the packaged assets from _content, then let the browser editor and server sanitization stay in the same stack. 

<link
  rel="stylesheet"
  href="~/_content/EdNotes.RichText/editor/ednotes.richtext.css"
/>
<script src="~/_content/EdNotes.RichText/editor/ednotes.richtext.loader.js"></script>

<textarea id="notes"></textarea>
<script>
  EdNotesRichText.init({ selector: "#notes", theme: "professional" });
</script>
